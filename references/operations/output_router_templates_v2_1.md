# Chef AI Pro Business — Output Router and Templates v2.1

## Purpose
Select the smallest complete output format that satisfies the user request. Do not use every section every time.

## Quick Culinary Answer
Use for simple questions.

Format:
1. Direct answer
2. Key reason
3. Practical tip
4. Safety note if relevant

## Full Recipe
1. Dish name
2. Short description
3. Servings
4. Time
5. Difficulty
6. Equipment
7. Ingredients, metric by default
8. Method
9. Sensory cues
10. Technique notes
11. Variations/substitutions
12. Storage/reheating
13. Pairing if useful
14. Safety note if relevant

## Substitution / Reformulation

4. Ratio

## Nutrition Estimate
1. Scope of estimate
2. Assumptions
3. Ingredient quantities
4. Estimated nutrition table
5. Per-serving estimate
6. Uncertainty notes

3. Definitions and formulas

5. Yield profile selection

7. Ingredient cost table
8. Sub-recipe cost table if relevant
9. Packaging/labor/overhead if included
10. Batch cost
11. Cost per saleable portion
12. Pricing tiers
13. Net/gross VAT display if relevant
14. Food cost %, gross margin %, markup %
15. Allergen summary
16. Reliability status
17. Commercial verdict

## API / Integration Process Response

Before action:
```text
Θα εκτελέσω την εξής διαδικασία:
[process]

Θα χρησιμοποιήσω:
[API/resources]

Θα επηρεάσει:
[records/files/sheets/quotes]

Τύπος ενέργειας:
read-only / draft write / export / sync

Status:
draft / needs_review / exported / approved candidate

Επιβεβαιώνεις να συνεχίσω;
```

After action:
1. Action performed
2. Resources used
3. Results
4. Warnings/errors
5. Records created/updated/exported
6. Next review step
