# The Mart Capture Tool — HTML + CSV/XLSX + ZIP

Αυτό το πακέτο είναι για νόμιμη προσωπική/επαγγελματική χρήση μέσα από τον δικό σου λογαριασμό The Mart.  
Δεν ζητά ούτε αποθηκεύει κωδικούς. Ανοίγει browser, συνδέεσαι εσύ χειροκίνητα, και μετά αποθηκεύει τις σελίδες των κατηγοριών/υποκατηγοριών που ζήτησες.

## Τι κάνει

1. Ανοίγει Chromium μέσω Playwright.
2. Σε αφήνει να συνδεθείς στο themart.gr.
3. Περνάει από τις 12 βασικές κατηγορίες:
   - Οπωροπωλείο
   - Ιχθυοπωλείο
   - Γάλατα Τυριά & Είδη Ψυγείου
   - Κρεοπωλείο
   - Κατεψυγμένα Είδη
   - Αλλαντικά Αλίπαστα & Συνοδευτικά
   - Παντοπωλείο
   - Αρτοσκευάσματα
   - Πρωινό & Γλυκά Σνακς
   - Φυτικά & Ειδικής Διατροφής
   - Αναψυκτικά Νερά & Χυμοί
   - Κάβα
4. Ανακαλύπτει υποκατηγορίες μέσα στο ίδιο category path.
5. Κατεβάζει όλες τις σελίδες προϊόντων με `product_list_limit=60` και pagination.
6. Αποθηκεύει:
   - HTML ανά σελίδα
   - `products_raw.csv`
   - `products_raw.xlsx`
   - `captured_pages.csv`
   - τελικό ZIP αποτελεσμάτων

## Εγκατάσταση σε Windows

Άνοιξε Command Prompt ή PowerShell μέσα στον φάκελο του εργαλείου και τρέξε:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
python themart_capture.py
```

Εναλλακτικά, διπλό κλικ στο:

```text
run_windows.bat
```

## Χρήση

1. Θα ανοίξει browser.
2. Κάνε σύνδεση στο The Mart με τον δικό σου λογαριασμό.
3. Άνοιξε μια κατηγορία και βεβαιώσου ότι βλέπεις τιμές.
4. Πήγαινε στο παράθυρο του terminal και πάτα ENTER.
5. Το εργαλείο θα συνεχίσει αυτόματα.

## Αποτελέσματα

Θα δημιουργηθεί φάκελος:

```text
output/themart_capture_YYYYMMDD_HHMMSS/
```

και δίπλα του τελικό:

```text
output/themart_capture_YYYYMMDD_HHMMSS.zip
```

## Σημαντικές σημειώσεις

- Μην κλείσεις τον browser όσο τρέχει.
- Μην τρέξεις πολλά παράλληλα captures.
- Αν το site ζητήσει ξανά login, κάνε login και άφησε το script να συνεχίσει.
- Το αρχείο Excel είναι “raw extraction”. Για καθαρό costing workbook μπορεί μετά να γίνει mapping: προμηθευτής, κατηγορία, υποκατηγορία, SKU, προϊόν, μονάδα, καθαρή τιμή, ΦΠΑ, μικτή τιμή, ημερομηνία λήψης.
- Το script έχει μικρή καθυστέρηση ανά σελίδα για να μην πιέζει το site.
